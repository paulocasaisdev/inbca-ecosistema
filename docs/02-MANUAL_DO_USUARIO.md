# Manual do Usuário - Sistema INBCA

Bem-vindo ao manual de operações do sistema do Instituto Nilson Bispo (INBCA). Este documento visa instruir a equipe de recepção, médicos, psicólogos, instrutores e voluntários a utilizar o sistema.

---

## 1. Portal de Agendamento (Comunidade)
**Onde acessar:** `[URL_DO_SITE]/agendamento`

O Portal de Agendamento é a interface amigável onde os moradores (ou a própria recepção ajudando o morador) podem marcar consultas, exames ou participação em aulas.

### Como realizar um agendamento:
1. **Passo 1 (Serviço):** Selecione qual núcleo deseja atendimento: "Clínica Médica" ou "Esportes e Lutas". Clique em Próximo.
2. **Passo 2 (Identificação):** Preencha os dados básicos:
   - Nome Completo
   - CPF
   - Cartão do SUS (O sistema avisará em verde se o cartão for válido ou em vermelho se houver erro de digitação).
   - Se o paciente foi encaminhado por um Posto de Saúde (UBS), marque a caixinha e informe o nome do Posto.
3. **Passo 3 (Confirmação):** O sistema vai gerar um **Código de Consulta** (Ex: `INBCA-123456`). O paciente deve anotar este código para apresentar na recepção no dia marcado.

## 2. Prontuário Eletrônico (Núcleo de Saúde)
**Onde acessar:** `[URL_DO_SITE]/painel/clinica/prontuario/[id]`

Destinado a Médicos, Enfermeiros, Psicólogos e Terapeutas. Serve para registrar a história clínica do paciente.

### Como registrar um atendimento clínico:
1. **Sinais Vitais:** A equipe de triagem (ou o próprio especialista) deve preencher os dados de Pressão Arterial (PA), Glicemia, Peso e Altura na área "Sinais Vitais & Triagem".
2. **Atendimento:**
   - **Anamnese / Queixa:** Descreva o relato do paciente e os sintomas observados.
   - **Conduta / Prescrição:** Anote os medicamentos recomendados.
   - **Encaminhamento SUS:** Caso a complexidade exceda a capacidade do INBCA, informe para onde o paciente será direcionado na Rede Pública.
3. **Imprimir / Salvar:**
   - O botão **Imprimir Receita** gera uma via formatada para o paciente levar à farmácia.
   - O botão **Salvar Atendimento** grava os dados no histórico inviolável do paciente.

## 3. Chamada de Presença (Esportes e Terapias)
**Onde acessar:** `[URL_DO_SITE]/painel/esportes-terapias/chamada`

Destinado aos Mestres, Professores (Karatê, Boxe, Capoeira) e Instrutores.

### Como fazer o controle de frequência:
1. Ao abrir a página no dia da aula, o sistema carregará automaticamente a lista de alunos matriculados na turma (com a data de hoje pré-selecionada).
2. Note o aviso vermelho de **"Atestado Pendente"**. Alunos com este aviso não entregaram o atestado médico exigido para esforço físico. 
3. **Para dar presença:** Clique no botão verde com símbolo de "Check" (✓).
4. **Para dar falta:** Clique no botão vermelho com símbolo de "X" (✕).
5. Após concluir a lista, clique em **Salvar Presença da Turma**. O relatório ficará disponível para a coordenação avaliar os índices de abandono e engajamento comunitário.
